# Reference — verbatim Superpowers skills

Unmodified source for the two skills this project's workflow adapts, copied from
the [Superpowers](https://github.com/obra/superpowers) repo, one folder per
skill (mirroring upstream `skills/<name>/`). These are *reference only* — the
version we run is described in [`../README.md`](../README.md).

- [`brainstorming/`](brainstorming/) — Socratic design refinement.
  - `SKILL.md` — the skill itself.
  - `spec-document-reviewer-prompt.md` — reviewer prompt for the written spec.
  - `visual-companion.md` — optional browser mockup companion guide.
- [`writing-plans/`](writing-plans/) — detailed implementation plans.
  - `SKILL.md` — the skill itself.
  - `plan-document-reviewer-prompt.md` — reviewer prompt for the written plan.
