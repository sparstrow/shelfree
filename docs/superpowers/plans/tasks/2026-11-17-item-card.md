## Rules
- Same sections, fields, defaults, read-only fields and footer buttons as the prototype.
- Saving goes through `useUpsert('items')`; after save, go where the prototype goes (profile or list).
- Stock quantities are NOT editable here (only receipts / assembly / transfers move stock).
- Category, unit of measure, vendor etc. use selects fed by the existing collections; if the
  prototype uses a lookup the app doesn't have for that source, use a select and note it.
- Ctrl+S saves, Esc goes back (with the prototype's unsaved-changes behaviour if it has one).

## Acceptance

next number; save blocked with a validation error first, then a valid item saves and appears in the
list; Edit from the Item profile opens the card filled; change the price, save, and see it on the
profile; Esc returns.
