## Rules
- Phone and email masked in the grid and exports, full in the drawer.
- View mode shows a **LINKED TO** section (through `extra`): one row per link
  (kind · number · name · role, with a "Primary" tag), each a button that navigates to that
  record's list with `?sel=<no>` (`/purchasing/vendors`, `/sales/customers`, `/purchasing/carriers`).
- **Delete is blocked while the contact is linked** — use the prototype's message.
- When the contact has links, show the prototype's shared-edit warning (edits to name / phone /
  email apply everywhere it is linked) as the view-mode `notice`.
- Number: automatic `CON#####` (next free), read-only.

in the grid and full in the drawer; a linked contact shows LINKED TO with a working link to its
vendor, and Delete disabled; create a new contact (validation first), edit it, delete it;
N opens a new contact.
